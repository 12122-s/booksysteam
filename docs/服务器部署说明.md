# 服务器部署说明

面向 Linux 服务器（虚拟机 / 云主机），**不使用 Docker**：装好 JDK 17 和 MySQL 8，
上传一个 jar 文件，用脚本或 systemd 启动即可。

---

## 一、本地打包

```bat
cd /d D:\IdeaProjects\booksysteam
mvnw.cmd package -DskipTests
```

产物：`target\booksysteam-1.0.0.jar`（约 57 MB，自带 Tomcat，服务器上不需要另装 Tomcat）。

> Windows 上如果 `mvnw` 报找不到 java：本机 PATH 里的 Oracle `javapath\java` shim 已损坏
> （执行 `java` 无任何输出），先设好 JAVA_HOME 再执行：
> `set JAVA_HOME=C:\Program Files\Zulu\zulu-17`

## 二、服务器准备

### 1. 安装 JDK 17

```bash
# Ubuntu / Debian
sudo apt update && sudo apt install -y openjdk-17-jre-headless

# CentOS / RHEL / 阿里云 Linux / 龙蜥
sudo yum install -y java-17-openjdk        # 报找不到包就换：sudo dnf install -y java-17-openjdk

java -version        # 确认是 17+
```

**下载慢就换国内镜像**（清华源，免安装，约 45 MB）：

```bash
cd ~/library-java
curl -LO https://mirrors.tuna.tsinghua.edu.cn/Adoptium/17/jre/x64/linux/OpenJDK17U-jre_x64_linux_hotspot_17.0.20.1_1.tar.gz
mkdir -p jre
tar -xzf OpenJDK17U-jre_x64_linux_hotspot_17.0.20.1_1.tar.gz -C jre --strip-components=1
echo 'export PATH="$HOME/library-java/jre/bin:$PATH"' >> ~/.bashrc
source ~/.bashrc
java -version
```

> ARM 架构服务器（`uname -m` 显示 `aarch64`）把链接里的 `x64` 换成 `aarch64`。
> 宝塔面板装的 JDK 一般在 `/www/server/java/jdk-17*/bin`，把它加进 PATH 或写完整路径即可。

### 2. 安装 MySQL 8

```bash
sudo apt install -y mysql-server        # CentOS：sudo yum install -y mysql-server
# 或者用宝塔面板 →「软件商店」→ 安装 MySQL
```

数据库不用手动建：程序首次启动会自动建库建表（库名由 `LIB_DB_NAME` 决定，脚本里默认 `library_java`）。

## 三、上传并启动

**服务器上建目录：**

```bash
mkdir -p ~/library-java
```

**在你自己电脑上执行**（把用户名和 IP 换成实际的）：

```bash
scp target/booksysteam-1.0.0.jar 用户名@服务器IP:~/library-java/
scp deploy/start.sh 用户名@服务器IP:~/library-java/
```

也可以用宝塔面板、FinalShell、WinSCP 这类图形工具，直接把这两个文件拖进 `~/library-java`。

**改数据库密码并启动：**

```bash
cd ~/library-java
vi start.sh          # 只改 DB_PASSWORD="你的MySQL密码" 这一行
bash start.sh        # 启动
```

其他常用命令：

```bash
bash start.sh stop   # 停止
tail -f app.log      # 看实时日志
```

浏览器打开 `http://服务器IP:8081`，管理员 `admin` / 初始密码 `123456`。

### 打不开先查这三处

1. 宝塔面板 →「安全」→ 放行 `8081`（协议 TCP）；
2. 云服务商控制台 → 安全组 → 放行 `8081`；
3. 用**公网 IP** 访问：`172.`、`10.`、`192.168.` 开头的是内网地址，外面访问不了。

## 四、开机自启（推荐）

`nohup` 方式在服务器重启后需要手动再启动一次；配成 systemd 服务即可开机自启、崩溃自动拉起：

```bash
sudo tee /etc/systemd/system/library-java.service > /dev/null << 'EOF'
[Unit]
Description=Library Management System (Java)
After=network.target mysql.service

[Service]
User=你的用户名
WorkingDirectory=/home/你的用户名/library-java
Environment=LIB_DB_HOST=127.0.0.1
Environment=LIB_DB_PORT=3306
Environment=LIB_DB_USER=root
Environment=LIB_DB_PASSWORD=你的密码
Environment=LIB_DB_NAME=library_java
Environment=SERVER_PORT=8081
ExecStart=/usr/bin/java -jar /home/你的用户名/library-java/booksysteam-1.0.0.jar
Restart=always
RestartSec=5

[Install]
WantedBy=multi-user.target
EOF

sudo systemctl daemon-reload
sudo systemctl enable --now library-java
sudo systemctl status library-java      # 看状态
journalctl -u library-java -f           # 看实时日志
```

> 把两处 `你的用户名` 和密码换成实际值。
> `WorkingDirectory` 很重要：封面目录 `uploads/` 和备份目录 `backups/` 都建在这里。
> 用宝塔装的 Java，`ExecStart` 换成 `/www/server/java/jdk-17*/bin/java`。

## 五、nginx 反向代理（可选，用 80 端口对外）

```nginx
server {
    listen 80;
    server_name 你的域名或IP;

    location / {
        proxy_pass http://127.0.0.1:8081;
        proxy_set_header Host $host;
        proxy_set_header X-Forwarded-For $remote_addr;
        proxy_read_timeout 60s;
    }
}
```

改完 `sudo nginx -s reload`。配了 HTTPS 的话，证书用 `certbot --nginx` 一条命令即可。

## 六、部署后检查

```bash
curl http://127.0.0.1:8081/health         # 返回 ok 即正常
curl http://127.0.0.1:8081/api/v1/books   # 返回 401（未带 token）说明 API 也起来了
```

- 登录后**第一件事**：改管理员密码，检查「系统设置」里的借期、罚金等规则；
- 换服务器 / 迁移数据：用「系统设置 → 导出完整备份」下载 `.sql`，在新机器「恢复」里上传导入。

## 七、常见问题

| 现象 | 原因与处理 |
| --- | --- |
| `nohup: failed to run command 'java'` | 服务器还没装 JDK，或 `java` 不在 PATH：按第二节安装；实在找不到就把 `start.sh` 里的 `java` 换成完整路径 |
| `Access denied for user ...` | `start.sh` 里的 `DB_USER` / `DB_PASSWORD` 不对 |
| `Communications link failure` | MySQL 没启动，或 `LIB_DB_HOST` / `LIB_DB_PORT` 不对 |
| 本机能访问、外面打不开 | 端口没放行：宝塔「安全」和云安全组都要放行 `8081` |
| 页面报 HTTP 500 | 看日志定位：`tail -50 app.log` |
| 封面上传失败 | `uploads/` 目录权限不足：`chown -R 用户名 ~/library-java` |
| 登录后一直跳回登录页 | 系统重启会让所有会话失效，重新登录即可 |
| 提醒邮件发重复了 | 同一套数据库跑了多个实例，只保留一个，或在「系统设置」里关掉到期提醒 |
